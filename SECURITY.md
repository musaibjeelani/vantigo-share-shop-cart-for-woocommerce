# Security reporting

Please do not disclose exploitable vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's **Report a vulnerability** option on this repository if private vulnerability reporting has been enabled. If that option is unavailable, contact the maintainer through the [Vantigo Systems website](https://vantigosystems.com) to arrange a private reporting channel before sharing sensitive details.

Include the affected plugin version, relevant WordPress/WooCommerce versions, reproduction steps, prerequisites, and potential impact. Remove real customer data, passwords, and working private cart links. Test only on systems you own or are authorized to assess.

The latest stable release is the recommended starting point for verification. Historical version folders are not maintained in this repository.
